# Historical records

- `development/`: dated Developer reviews, implementation handoffs and integration records.
- `qa/`: earlier QA plans and DEV-003 integration/hook notes.

These records retain their original contents, filenames, dates and identities.
Relative paths and commands within them may describe the former layout. Resolve
current locations through the documentation index and repository-layout guide;
Git history still provides the original paths. Do not treat an old candidate's
failures or pending policy as the current candidate's result.
